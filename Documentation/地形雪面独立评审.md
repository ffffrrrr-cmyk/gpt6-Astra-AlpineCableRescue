# 地形与雪面独立视觉评审

## iteration-02：FAIL

评审日期：2026-11-06。只依据本轮 9 张 PNG 和真实摄影作视觉判断，未读取源代码、旧截图、开发说明或开发者自评，未做键鼠试玩。静态截图不能证明碰撞、运动表现和操作手感通过。

证据：`shots/new/iteration-02/` 内 `menu.png`、`mission-0.png`、`mission-1.png`、`mission-2.png`、`mission-3.png`、`terrain-cliff-detail.png`、`terrain-overhead.png`、`terrain-snow-detail.png`、`terrain-supports.png`。

摄影参照：`Documentation/References/Untere_Stuhllochscharte.jpg` 及同目录 `摄影参照.md`。摄影者 Tadeáš Gregor，2017-12-03，奥地利 Untere Stuhllochscharte（2182 m），CC BY-SA 4.0。参照用于观察岩壁断裂、顺坡积雪、厚雪轮廓和近景颗粒；黑白摄影不用于判定游戏色温，也不是所有高山地貌的唯一模板。

### 本轮范围内阻塞项

1. **岩壁的大形和层理过于规则。** `menu.png`、`terrain-supports.png`、`terrain-cliff-detail.png`、`terrain-overhead.png` 中，大面积崖壁呈均匀横向波纹和格状裂缝，像连续贴纹理的厚墙。摄影参照中的岩壁具有尺度不同的断裂、斜切面、突出岩柱、沟槽与遮蔽关系；本轮纹理不能替代这些体积。应先打破连续直立面，加入不等宽裂隙、倾斜层面、局部突出与凹陷，再减少等距细纹覆盖。

2. **近景积雪呈密集泡沫坑洞，缺乏可信的风与重力作用。** `terrain-snow-detail.png` 最明显：相近尺度的凹坑与圆包铺满整个面，坑内裸岩重复出现，近处表面模糊且部分边缘显出尖锐三角形。真实参照中厚雪连续包覆地形，边缘圆润，近处颗粒细密；并非到处同样密集地穿孔。应显著降低裸岩孔洞密度，把露岩集中在凸起、迎风处及陡坡；以连续厚雪、顺坡沟槽和少量方向一致的风纹建立中尺度形态，最后补充细颗粒。避免用增加随机噪声代替雪的层次。

3. **碎石与山脚过渡不足以建立自然地貌。** `terrain-overhead.png`、`terrain-supports.png` 中，块石可见，但主要表现为稀疏独立多面体；崖壁与谷底之间缺少清楚的崩落堆积坡和粒径变化。应让碎石在沟口、崖脚聚集，形成连续斜坡，朝远离岩壁处逐步变小、变稀，并有部分埋雪的接触关系。

4. **任务岩柱仍有明显基础几何体观感。** `mission-1.png`、`mission-3.png` 前景独立岩体为平滑大面多面体，顶端雪块呈孤立尖角，与周围岩壁及厚雪不一致。它属于可见地形，故列入本轮范围。应破坏平整面与规则轮廓，增加与环境一致的层理和断裂，让雪沿岩顶、沟槽及台阶连续堆积。仅将物体细分或加噪声不等于修复大形。

本轮可确认已有峡谷、台地、覆雪斜坡和明显深度，不是全场单一平底锥形山；但画面未充分显示完整山体外轮廓，不能据此声称所有山体造型均达标。现有地形与雪面的上述问题足以判定 FAIL，无须借助范围外问题降低或抬高判定。

### 目标可读性与结构观察

- 橙色救援舱、青色落区在 `mission-0.png` 至 `mission-3.png` 中可辨认，落区未被地形完全挡住；`mission-2.png` 可区分两种色环。静态目标颜色可读性基本成立。
- `terrain-supports.png` 与 `terrain-cliff-detail.png` 中，平台多根立柱在岩壁前终止，画面未显示其落地或锚固，产生悬空印象。应核实并让地形接触或基础位置可见；若必须改机械资产才能解决，应作为独立范围决定，不借本次地形评审强制扩展。此项影响结构可信度，不能由“看得到支柱”推导为结构合理。
- `menu.png` 中索道支架与线缆易识别；任务视图的支架局部受画幅与 HUD 遮挡。仅凭本组静态截图不能确认所有操作视角与运动阶段持续可读。

### 范围外观察：记录问题，不要求本轮越界修改

- **树木资产：** 多张截图中的树木为重复叠锥形，限制整体写实性。本轮不以改树作为地形/雪面 PASS 的前置条件。
- **机械及吊钩资产：** 吊钩尺寸小、吊环细，局部黑色标签与其投影接近；这里只记录识别风险，不要求重制机械或吊钩。
- **HUD：** `mission-3.png` 双目标标签与两组舱体挤在同一区域，部分实体被覆盖。后续交互评审可检查，但不作为本轮地形改造指令。
- **文案：** `menu.png` 写“右侧青色接应区”，但该截图接应区位于左下。这是屏幕方位文案问题，独立记录。
