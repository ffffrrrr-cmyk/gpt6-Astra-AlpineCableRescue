# 来源与权利状态

项目 U1 为新生产游戏工程。当前核心代码由本聊天实际运行模型 gpt-6-astra 生成，服务产品为 OpenAI Codex；套餐、具体服务快照、采购名单别名映射及输出用途条款仍待采购核验。用户已明确授权在这些缺项标待补的前提下先行开发。
