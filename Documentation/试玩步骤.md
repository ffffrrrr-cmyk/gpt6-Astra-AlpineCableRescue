# 用户试玩清单

预计 15—20 分钟。启动 `Builds/Windows/FrostlineRescue.exe`，建议 1600×900 或 1920×1080；先正常模式训练，必要时使用自由练习熟悉操作。以下为待用户执行的步骤，未收到反馈不记为通过。

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 开始首关，阅读并关闭引导 | 出现山谷、吊机、橙色救援舱、青色接应区和实时仪表 |
| 2 | 用 E 放缆，在吊环附近按 Space | 近距离低速时可锁接；过远或过快时说明原因且不误锁 |
| 3 | Q 收缆后轻按 A/D，再松开 | 载荷真实摆动并逐渐衰减，吊机有限加速度，钢缆和舱体保持连接 |
| 4 | 用 C 切换三种视角 | 全景、跟随吊钩、俯视均能看清作业；HUD 保持可读 |
| 5 | 按 Esc 暂停，等待数秒后恢复 | 载荷、风场、任务计时停止；恢复时不跳跃或异常甩动 |
| 6 | 降到接应圈，停稳并解锁 | 支承成立且稳定约 1.2 秒才允许解锁；每舱计分一次，完成后出现结算 |
| 7 | 返回调度并重新启动游戏 | 首关成绩和第二关解锁保留 |
| 8 | 第二关故意较快触碰岩壁，再按 R | 损伤与提示可读；重试后损伤、载荷、关节和计时回到初态 |
| 9 | 第三关在中继台解锁后重接 | 中继不直接算最终完成，目标切换为高台 |
| 10 | 第四关观察阵风并完成两舱 | 阵风前预警，风力影响载荷，两舱分别交付，不重复计数 |
| 11 | 调整音量、灵敏度和画质，再重启 | 设置保存；静音有效，低画质仍可操作 |

反馈时说明关卡、操作、实际现象、希望调整的方向，以及可选的截图或录屏。优先关注：吊钩瞄准难度、摆动衰减速度、落区易读性、HUD 遮挡、机械资产与山谷画面、帧率和输入延迟。只复测受修复影响的内容。
